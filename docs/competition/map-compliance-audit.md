# 地图合规专项审计（Map Compliance Audit）

> **正式版本采用国家地理信息公共服务平台（“天地图”）提供的地图服务；**
> **地图内容仍由参赛者在提交前按照赛事规范进行人工检查。**
> 本作品不通过 AI 自行绘制中国地图；本审计只陈述事实，**不下“已通过地图审核 / 已获审图批准”结论**，
> 除非取得相应正式证明（审图号等）。

## 历史记录（如实保留）

- 开发阶段（Round 1–7）曾使用 **CARTO Dark Matter**（OpenStreetMap 派生的境外底图，无中国审图号）
  作为背景底图。**提交前已移除 CARTO**：正式 REAL 模式不再请求 `carto.com` / `basemaps.cartocdn.com`
  任何瓦片或样式（构建产物可核实，见 network-dependency-audit.md）。

## 人工检查清单（提交前必须逐项）

1. **中国国界 / 台湾 / 海南 / 南海诸岛（九段线）/ 海岸线**：在天地图底图上的实际显示结果逐项目视检查。
2. **版权 / 署名**：天地图 attribution（`© 国家地理信息公共服务平台 天地图（tianditu.gov.cn）`）
   必须可见、不被底部时间轴等 UI 遮挡（已通过 CSS 提升底图控件位置）。
3. **审图相关显示**：如赛事 / 平台要求审图号，按赛事规范办理；未取得正式证明前，
   代码与文档**不得写**“本作品已通过地图审核”“本地图已获审图批准”。
4. **禁止事项**：不得删除 provider attribution；不得修改国界；不得 AI 重绘国家版图；
   不得自造所谓“合规中国边界”。

## 结论

- 底图已替换为官方天地图服务（直连 `tianditu.gov.cn`，无第三方代理、无转包瓦片）。
- 最终地图内容合规仍属**参赛者人工责任**：按上述清单在提交前检查并记录检查结果。
