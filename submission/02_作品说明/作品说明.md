## 主题立意

面向普通公众与青少年，把一场真实台风——2024 年第 11 号台风“摩羯”（YAGI，2411）——的完整生命旅程，
用一张交互地图和六个环环相扣的问题讲成一个可以“亲手追一遍”的故事：它从哪来、往哪去、在哪登陆、
哪里更危险、AI 能做什么、人该怎么做。

作品同时诚实回答一个更深的问题：**AI 在地理科普里到底能做什么、不能做什么**。在本作品中，AI 的角色
严格限定为数据处理、代码编写、质量核验与叙事表达四类辅助，所有科学事实来自可追溯的权威数据并经人工核验，
AI 不自主得出任何科学结论。

## 作品简介

一部**纯静态、单页交互式台风地理科普网页**。以地图（MapLibre GL）为视觉中心，叠加：

- 摩羯真实历史轨迹（36 个时次）；
- 两次真实登陆事件（海南文昌、广东徐闻）；
- FY-4B 卫星真彩云图（6 帧）与 NOAA 海表温度（2 帧）；
- 地形、人口暴露、路径邻近度三因子构成的科普型空间关注提示，支持地图点击查询。

配合六章节导航、底部时间轴播放、图层开关与透明度调节，让用户沿着“六个问题”走完一场真实台风的旅程。
技术栈：React 19 + Vite 7 + TypeScript + MapLibre GL JS 5 + ECharts 5 + 原生 CSS，`base: './'` 纯静态部署。

## AI 使用方式

- **AI 角色（四项，均为辅助）**：多源数据整理、数据处理与可视化代码编写、质量核验、科普叙事表达。
- **没有机器学习模型**：无模型训练、无权重、无随机种子，也不存在训练 / 验证 / 测试集划分。
- **AI 不自主得出科学结论**：AI 生成的处理代码与中间结果，全部经人工核验后写入；科学事实以权威资料为准。
- 真实人工审核案例：台风网原始字段 `nmcLandfallFlag` 因官方语义无法证实，改名为 `nmcFlagRaw` 并禁用为登陆标志；
  FY-4B SST 有效像元不足（云覆盖）时拒绝插值，改以 NOAA 分析场作展示层；缺少完整权威风圈时拒绝伪造、保持占位；
  风险结果明确标记为 derived analysis（科普型，非官方灾害风险预报）。

## 主要数据

全部本地静态加载，真实数值可追溯（机构 / 产品 / UTC 时间 / URL / 处理说明）：

- **轨迹**：中国气象局台风网官方历史数据，36 时次，13–62 m/s、915–1004 hPa，2024-09-01 00:00Z–09-08 12:00Z；
- **登陆**：两次——2024-09-06 文昌翁田镇 08:20 UTC（62 m/s / 915 hPa）、徐闻角尾乡 14:20 UTC（58 m/s / 925 hPa），
  数值出自中央气象台业务通报原文，坐标为地名地理编码（仅可视化）；
- **卫星云图**：FY-4B AGRI 真彩 6 帧（国家卫星气象中心）；**SST**：NOAA Coral Reef Watch 日分析场 2 帧（°C）；
- **风险因子**：Copernicus DEM GLO-30 地形、Kontur Population 400m H3 人口、路径邻近度（derived analysis）、
  科普型空间关注提示（三因子确定性规则，derived-analysis，science-communication-only）；
- **风圈**：数据缺失，未伪造、未插值，界面保持“待接入”占位。

## 科学性说明

- **数值零编造**：所有真实数值必须可追溯；处理后图像不冒充“原始卫星数据”。
- **REAL / DEMO 严格隔离**：真实数据与合成演示数据物理隔离，真实数据未就绪时显示“待接入”，绝不静默回退到演示数据。
- **缺失即缺失**：风圈等无权威数据的部分保持占位，禁止插值 / 反推冒充完整数据。
- **示意 ≠ 真实**：机制示意图、预测不确定性示意、空间关注提示三类均明确标注，不冒充真实大气分析场、集合预报或官方风险预报。
- **确定性规则可审计**：风险关注分级写成可审计文本，标记 derived-analysis + purpose=science-communication-only。

## 使用方法

1. 打开正式访问 URL（见 submission/01_作品/website-link.txt），推荐 Chrome / Edge，1366×768 或 1920×1080；
2. 点击“开始追风”，按 01→06 顺序浏览六章节；
3. 使用底部时间轴查看轨迹随时间的演进与登陆时刻高亮；
4. 在图层控制中切换轨迹 / 登陆点 / 卫星云图 / SST / 风险因子等图层，调节卫星透明度；
5. 在地图上点击任意位置，查看高程、人口暴露、距路径距离与科普型空间关注提示；
6. 随时查看每项数据的“数据来源”入口，核对机构、产品与出处。
