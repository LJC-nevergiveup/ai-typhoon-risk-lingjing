# 运行说明

## 在线访问

- 正式访问 URL 见 `submission/01_作品/website-link.txt`（当前尚未部署，部署后填写）。
- 本作品为纯静态网页，无需安装、无后端、无账号系统；打开链接即可使用。

## 推荐环境

- **浏览器**：Chrome（最新版）或 Edge（最新版）。
- **分辨率**：1366×768 或 1920×1080（PC 优先，键盘鼠标操作体验最佳）。

## 操作步骤

1. **点击“开始追风”**：进入作品后，先看首次引导“跟着六个问题，一起追踪一场真实台风”，点击“开始追风”。
2. **顺序浏览六章节**：沿顶部 / 侧边导航按 01 台风从哪来 → 02 台风往哪去 → 03 台风在哪登陆 → 04 哪里更危险 → 05 AI能做什么 → 06 人该怎么做 依次浏览（章节旁有已读标记）。
3. **使用底部时间轴**：拖动 / 播放时间轴，查看台风轨迹随时间的演进；登陆时刻附近有 ▲ 标记与高亮窗口。
4. **切换图层**：在图层控制面板开关轨迹、登陆点、卫星云图、SST、风险因子等图层，并可调节卫星云图透明度。
5. **点击地图查询**：在地图上点击任意位置，查看高程、人口暴露、距路径距离与科普型空间关注提示（含免责声明）。
6. **查看数据来源**：在信息面板“数据来源”处查看每项数据的机构、产品、时间与出处，可核对真实性与口径。

## 本地运行（评委 / 复核者如需）

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 构建（产物在 dist/）
npm run preview    # 本地预览构建产物
```

> 说明：纯静态部署已配置 `base: './'`，可部署到 GitHub Pages 子路径 / Vercel 等；真实数据全部本地静态加载，无运行时联网抓取科学数据。

## 注意事项

- 正式底图为国家地理信息公共服务平台“天地图”（官方服务，需配置 `VITE_TIANDITU_TOKEN`；token 缺失/失败时自动降级为纯色背景并提示，核心科普数据不受影响）。
- 演示（DEMO）案例的卫星瓦片来自 NASA GIBS（仅界面验证用，正式 REAL 案例使用本地 FY-4B 影像）。
- 本作品为科普展示用途，风险提示为科普型派生分析，防灾避险以官方预警为准。
